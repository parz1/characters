# Codex CLI 适配器

本包是已实现的早期执行适配器，调用方向为 characters → Codex。2026-11-05 起冻结：只保留兼容回归，不新增功能；路线图 R5 前评估是否移除。新的产品主线是宿主插件 → 管理服务，见[Codex 插件设计](../../docs/codex-plugin.md)。这里的执行协议、认证副本及禁用全部执行工具的证据不能直接用于新的宿主插件，也不要求插件依赖本执行器。

CodexCliAdapter 通过新进程执行一次讨论或建议稿生成。probe 使用本机模拟服务捕获当前二进制发出的请求，验证记忆标记没有注入、文件工具没有暴露，并记录版本与二进制摘要。

真实执行使用独立配置目录、只包含短期认证字段的副本、关闭记忆与执行工具的配置，以及固定结构化输出。结果在临时目录清理和原记忆目录元数据比较成功后才返回。原用户认证和记忆正文不会进入模型输入。

当前支持 ChatGPT 文件登录，不使用 API key，不复制 refresh token。默认不运行真实模型测试；probe 无需认证或真实 API 服务。常规测试中找不到 Codex 时，明确跳过实际二进制探测，不把模拟适配器当作真实隔离证据。

详见 [试用指南](../../docs/codex.md)。通用 stdio worker 协议尚未实现；当前适配器直接翻译 Codex CLI 的 JSONL 事件与结构化结果。
