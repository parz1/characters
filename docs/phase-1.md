### 原完成标准（存档）

以下是 2026-10-25 制定的原标准，保留作为历史记录。其中依赖 Codex strict 的条目已转为[实现状态](status.md#宿主隔离认证)中的宿主认证项，其余条目由路线图 R1–R3 继承。

- 用户显式启动一个工作区的管理进程，连接多个独立客户端，不共享全局活动角色。
- Codex 安装一次通用接入包后，可发现已授权角色，在自己的原生会话加载 Koto 并交流。
- 本次角色定义、相关记忆、来源和版本均可解释，跨工作区、角色、会话授权不串入。
- 宿主仅提交候选记忆；用户管理 CLI 审核后，新绑定能检索到。搜索不提升候选。
- 授权撤销、到期、服务重启与网络重试有明确结果，不能产生无授权访问或重复决定。
- 至少一个实际 Codex CLI 版本通过本会话隔离检查；证据不足时只能标记“工具接入完成，strict 未验收”。
- 不需要管理 GUI、模型 API key、characters 自有聊天界面、文章作品或全局角色安装。
- 角色启停只影响其绑定线程：不改全局/项目开关、共享配置或其他会话的记忆模式。关闭后不恢复含角色历史线程的全局记忆生成。

“协议测试通过”“Codex 工具可用”“真实 strict 已验证”分别记录，不能互相替代。

- [x] 固定本地 Codex CLI 0.164.0-alpha.11.1，验证兼容插件清单、临时本地市场安装与 stdio 工具。生产技能路由仍在 M5 验收。

- [x] 保存可重复脚本、回归与结构化能力报告，明确“受控 App Server 可行，现有 TUI/桌面未验收”。

M0 完成的是调查与有界实验，不是 M5 strict 交付。原生插件怎样安全取得当前会话控制、技能路由、fork/恢复/压缩、完整预算与后台记忆提取仍需后续验证；不能复用实验报告当作真实会话能力证据。

先做无模型调用的包校验、帮助/协议检查与本地捕获。真实模型验证需要用户单独授权；不沿用早期执行试用的授权作为本轮新测试许可。

完成条件：能确定本轮 Codex 插件的实际打包和会话关联方式，或明确写出阻塞项。M1 至 M4 的宿主无关工作可继续；如果 M0 无法验证会话记忆边界，M5 strict 交付保持未完成，不以通用说明或“用户说已关闭”代替证据，也不自动改成 Codex 启动器。

### M2：工作区管理服务

- [x] 新建 packages/service，绑定显式 WorkspaceHandle，仅监听回环随机端口。
- [x] 实现前台 service serve/status/stop，独立服务 owner、描述符和安全停机。
- [x] 实现管理/agent 凭证分离、最小范围 ConnectionGrant、ACL/权限及撤销。
- [x] 实现绑定创建/关闭/到期、固定角色 digest、会话唯一性、证据和授权 revision 检查。
- [x] 每次交付/写回在返回或提交前再次检查撤销；变更、访问记录和回执同事务。
- [x] 服务重启恢复 P2 事务并终止旧世代活动绑定，不自动恢复激活或启动宿主。

验收：两个模拟宿主 session 使用不同角色，关闭或撤销 A 不改变 B；旧回执不能绕过授权、绑定、证据与世代检查。CLI 前台生命周期、失效描述符、外地主机 owner、无凭据、请求预算、崩溃接管与到期检查已覆盖。验证器在存储锁外运行。已确认经历共享与候选隔离属于 M3 业务验收，不由 M2 结构测试代替。真实宿主验证器仍在 M5，CLI strict 默认拒绝；没有修改任何 Codex 全局配置。

已验收：本地 HTTP 与合成演示完成“加载 → 候选 → 审核 → 新绑定检索 → 撤回后不再命中”；跨角色、项目、contextKey、关闭与旧回执均有回归。替代审核的两项状态、审计与回执在进程中断后一起恢复。另提供显式共享背景导入 / 撤销。来源仅标注宿主提交，不声称独立验证聊天真实性。运行命令和限制见[记忆闭环指南](memory.md)。

## 验证矩阵

| 场景                | 必须观察到的结果                                                 |
| ------------------- | ---------------------------------------------------------------- |
| 两工作区安装同 Koto | 私有标记不跨工作区交付或命中                                     |
| 同工作区两个角色    | 以相同 query 检索也不返回另一角色记忆                            |
| 同项目两个宿主窗口  | 独立会话/绑定/恢复记录；切换 A 不改变 B                          |
| 同一角色并发使用    | 已确认记忆按授权共享，候选来源不串、确认 revision 冲突可解释     |
| 项目与背景范围      | 不在授权 projectKey/contextKeys 内的数据在排序之前被排除         |
| 候选不升级          | 搜索、重启、摘要/索引重建均不把 candidate 转 confirmed           |
| 审核、替代、撤回    | 决定需管理身份；新查询不含失效条目，历史记录仍可审计             |
| 来源最小化          | 只保存提交摘录，不抓取整份宿主会话或任意路径                     |
| 授权与证据失效      | 过期/撤销后的旧绑定和 snapshot ID 不能继续下载正文               |
| 撤销与进行中请求    | 撤销确认后不再提交/释放新内容；已交付内容明确无法追回            |
| 重试与版本冲突      | 同请求只提交一次；不同参数同 ID 冲突，旧 revision 不覆盖新决定   |
| 服务/网关中断       | 不调用模型、不离线重复写入；重启恢复完整事务，旧绑定 interrupted |
| 凭证和路径边界      | stdout、模型参数、错误、快照无凭证；伪造路径/角色/actor 被拒绝   |
| 预算与协议异常      | 超限、未知字段/版本、宿主工具截断均有明确失败或排除清单          |
| strict 证据         | 模型自述和 clientInfo 不足以通过；版本/配置/会话变化使旧证据失效 |
| 宿主已有上下文      | 关闭只阻止后续访问，不宣称从宿主聊天或提供商中删除               |
| 兼容回归            | 原 P1/P2、早期 Codex 执行切片继续通过测试                        |

所有常规测试只使用临时工作区、假凭证和模拟服务；实际 Codex 二进制捕获也不得访问真实凭证或模型。真实交互验收需明确授权。文件元数据未变只是辅助证据，不足以证明没有读取；模型回复没提诱饵也不是隔离证明。
