## 已知体验缺口

以下是 R1 要处理的已知问题，详见[路线图](roadmap.md#r1koto-体验基线无模型)：

- 正反例被打包但不在 context.get 交付项中。
- 关键词检索按空白分词，中文整句查询基本不会命中。
- 无查询时默认交付按 ID 顺序取前 32 条记忆。
- 参考客户端 `/remember` 不能替代旧记忆，也不能选择 mode。

## 记录规则

“协议测试通过”“工具接入可用”“角色表现通过”“宿主 strict 认证通过”分别记录，不能互相替代。relaxed 下的使用结果不能改写为 strict 通过。真实模型或真实宿主未运行的项标“未执行”，缺宿主证据标“受阻”。
