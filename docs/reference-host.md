# 本地参考测试客户端

2026-10-27：已实现独立薄参考客户端，首个后端为 DeepSeek。characters 仍是角色性格与记忆管理系统。客户端可以移除，不改变 Core、服务、角色包和记忆格式；未引入 pi 或 LangGraph。Codex 插件暂缓，dsh 插件后续单独调查和验收。

## 一条命令开始

完成 `pnpm install --frozen-lockfile` 和 `pnpm build` 后，在项目目录运行：

```powershell
pnpm characters chat kurisu
```

未配置 DeepSeek API key 时，交互终端会提示隐藏输入：粘贴自己的 key 后按回车，仅在本次进程内使用、不保存、不回显。也可使用环境变量，或应用根目录 `.env.local` 中的 `DEEPSEEK_API_KEY`。不需要手动配置 PowerShell 会话变量、解析中文 JSON 或安装 Codex；未保存的 key 下次启动需重新输入。不要把 key 粘贴到聊天记录或提交仓库。

默认使用应用根目录 `.local/data`，与 CWD 无关。新空目录自动初始化、启用服务数据格式、安装所选内置角色。非空陌生目录拒绝覆盖；已有角色不自动升级，旧工作区不隐式迁移。若提示未迁移，显式运行 `workspace migrate --target service-v1`。支持 `--workspace PATH`。

客户端只启动自己拥有的服务，退出时关闭绑定、撤销本次授权并停止自己的服务。首版每个工作区同时支持一个自包含参考客户端；已有管理服务或另一客户端持锁时返回 BUSY，不接管、不停止已有进程。并行独立实验请使用不同工作区。

## 对话命令

| 输入             | 行为                                                          |
| ---------------- | ------------------------------------------------------------- |
| 普通文字         | 流式回复，本次进程内继续对话                                  |
| `/search 查询`   | 经服务检索当前角色与授权范围内的已确认记忆                    |
| `/remember 内容` | 显式内容提交为 opinion 类型候选，显示 ID/revision，不自动确认 |
| `/new`           | 关闭旧绑定、撤销旧授权、清空本地历史，以相同角色建立新会话    |
| `/help`          | 帮助                                                          |
| `/exit` 或 EOF   | 正常退出                                                      |
| Ctrl+C           | 取消当前请求并退出，部分回复不追加到历史                      |

模型只有 `memory_search` 工具。候选只能由用户 `/remember` 命令路径提交，摘录就是明确输入的内容，不采集整段聊天。普通聊天不会自动保存长期记忆；来源只标注宿主提交，不声称独立核实事实。

候选提交后会打印带真实 ID、revision、角色和工作区的管理端确认命令。可在另一终端执行，之后 `/new` 再检索。撤回仍用管理端 `memory retract`；模型没有确认、拒绝、撤回或授权工具。支持 `--project KEY` 固定逻辑项目，默认不读取任何共享 contextKeys。

## 模型与预算

默认模型 `deepseek-flash`，地址 `https://api.deepseek.com`。支持 `DEEPSEEK_MODEL` / `DEEPSEEK_BASE_URL` 和 `--model` / `--base-url`。配置的服务会收到角色上下文，请使用受信任地址。允许 HTTPS，普通 HTTP 仅允许回环 `127.0.0.1` 模拟服务；禁止 URL 账号密码、查询、片段和重定向。

OpenAI SDK 7.43.0 仅用于 DeepSeek 兼容传输，不调用 OpenAI API，也不读取 OpenAI key。使用 DeepSeek 官方[兼容接口](https://api-docs.deepseek.com/)和[工具调用](https://api-docs.deepseek.com/guides/tool_calls/)格式；首版显式关闭 thinking，思考模式未验收。

每回合最多四次模型请求、八次只读工具调用。输入上限 8 KiB，模型消息 128 KiB，本地历史 64 KiB，显示文本 32 KiB，单次模型响应传输 1 MiB，模型请求超时 30 秒。超限明确失败，可用 `/new` 重新开始；不静默截断或自动摘要。禁止自动网络重试；认证、限流和网络错误脱敏展示。候选提交遇到不确定网络结果时，先在管理端查询状态，避免盲目重复提交。

聊天历史仅在进程内保存，不支持退出恢复。失败/取消的回合不进入历史；已显示文本无法收回。交付快照和检索工具结果不跨回合保存，每次模型请求（包括工具续答）重新获取服务上下文。已进入自然语言聊天历史的内容不能因记忆撤回而远程删除，使用新会话验证新检索结果。

## 数据和证据边界

CLI 作为用户启动的管理控制面，调用 Core/服务公开 API 初始化数据、安装角色、启动服务并为本次角色签发专属 agent 授权。模型运行代码只持有 agent RPC 回调；上下文、记忆、候选与绑定均经公开 `POST /v1/rpc`，不读取工作区文件、不调用 KnowledgeStore。服务不依赖模型 SDK，不接收模型 key，不运行 agent 循环。

同进程控制器仅为自己创建、配置固定且存活的参考会话提供服务端验证，核对 hostId/pluginId、sessionRef、connectionId。模型参数、clientInfo 和外部客户端不能注册通过。此证据限于本参考客户端没有宿主全局记忆读写机制，不是 Codex/dsh 的真实会话证明、OS 沙箱或提供商零留存承诺；生产外部宿主验证仍待解决。

关闭、撤销、过期、服务停机或世代变化后，后续公开接口访问失败，不离线加载正文。绑定最长一小时，过期后 `/new`。不会控制其他已有 daemon、改全局配置或重启公共 MCP。

自动测试使用隔离工作区、合成 key 和回环模拟 DeepSeek，覆盖中文流式、工具续答、角色/项目隔离、候选隐藏、人工审核、新会话取回、撤回、越权拒绝、有界循环、错误脱敏、取消、服务失效及 CLI 生命周期。没有调用真实模型或读取真实凭证；角色实际表达质量需用户交互评估。
